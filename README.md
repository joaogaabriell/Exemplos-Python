# Exemplos em Python

Repositório de estudos com exemplos introdutórios de **Python** em **Jupyter Notebooks**.

## Conteúdo

| Notebook | Conteúdo |
|---|---|
| `models/Exemplo_1.ipynb` | Operações aritméticas, entrada de dados (`input`), condicionais, verificação de número primo e jogo de adivinhação com `random` |
| `sample.ipynb` | Notebook de exemplo (Hello World) |

## Como executar

1. Instale o Jupyter:
   ```bash
   pip install notebook
   ```
2. Abra os notebooks:
   ```bash
   jupyter notebook
   ```

Também é possível abrir diretamente no PyCharm, no VS Code ou no [Google Colab](https://colab.research.google.com/).
